1. Executive Summary & Core Vision

EduID is an enterprise-grade digital identity platform created to modernize student credential management, academic history tracking, extracurricular verification, and AI-assisted career advisory into a secure, tamper-proof, verified digital registry.

Key Architectural Innovation: The platform enforces a Zero-Secrets Frontend Architecture. MongoDB connection strings, OpenRouter LLM credentials, and user password hashes reside exclusively on the server. Browser DevTools Inspect reveals no sensitive keys.

2. The EduID Specification Standard

Segment Type / Length Example Specification Description
Prefix 2 Characters EU Educational Universal namespace identifier.
State Code 2 Characters KA Official 2-letter uppercase ISO/postal state code (e.g. KA, MH, DL, TN).
Year 4 Digits 2026 Four-digit enrollment cohort year.
Unique Serial 3 Digits 001 Non-occurring 3-digit number (001–999) verified collision-free in MongoDB.

Storage & Normalization: Database primary key uses the compact format EUKA2026001. The presentation format uses EU-KA-2026-001. The backend normalizer cleans all punctuation and case on login, resolving euka2026001, EU-KA-2026-001, and EUKA2026001 identically.

3.1. Collision-Free EduID Generator Engine

Located in backend/utils/eduIdGenerator.js, this function ensures zero sequence collisions by querying existing user records and selecting only from remaining unallocated slots.

backend/utils/eduIdGenerator.js JavaScript (Node.js)
export async function generateUniqueEduId(state = 'KA', year = 2026, randomize = true) { const cleanState = state.trim().toUpperCase().slice(0, 2); const cleanYear = Number(year) || 2026; // 1. Retrieve all issued sequence numbers for state + year const existingUsers = await User.find( { state: cleanState, year: cleanYear }, { sequenceNumber: 1 } ).lean(); const usedNumbers = new Set(existingUsers.map(u => u.sequenceNumber)); const availableNumbers = []; for (let i = 1; i <= 999; i++) { if (!usedNumbers.has(i)) availableNumbers.push(i); } // 2. Deterministic or randomized unallocated slot selection const selected = randomize ? availableNumbers[Math.floor(Math.random() * availableNumbers.length)] : availableNumbers[0]; const padded = String(selected).padStart(3, '0'); return { eduId: `EU${cleanState}${cleanYear}${padded}`, formattedEduId: `EU-${cleanState}-${cleanYear}-${padded}`, sequenceNumber: selected }; }

3.2. Secure Authentication & Credential Stripping

Located in backend/routes/auth.js, this endpoint verifies credentials via bcrypt. Passwords and internal database keys are completely removed before the response is dispatched.

router.post('/login', async (req, res) => { const { eduId, password, role } = req.body; const compactInput = eduId.trim().replace(/[^a-zA-Z0-9]/g, '').toUpperCase(); // Flexible lookup matching either compact or hyphenated format const user = await User.findOne({ $or: [{ eduId: compactInput }, { formattedEduId: eduId.trim() }] }); if (!user || !(await bcrypt.compare(password, user.password))) { return res.status(401).json({ success: false, message: 'Invalid credentials' }); } // Respond with sanitized data (Password and DB keys NEVER sent to client) res.status(200).json({ success: true, user: { eduId: user.eduId, formattedEduId: user.formattedEduId, name: user.name, role: user.role, department: user.department, institution: user.institution, status: user.status } }); });
